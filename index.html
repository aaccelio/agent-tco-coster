Agent TCO — generic cost model for the Copilot Studio stack

Cost = sourced unit prices × volume drivers × retained baseline components, projected month by month. The PDE→TSA workbook is used only as a validation fixture, never as the model. Every price carries a source and a verification status — no invented numbers.

Baseline rule: never announce a price, quota, license or region without proof — “to verify” items need a targeted test in the tenant before committing.
